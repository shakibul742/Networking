# Networking

**Comprehensive Networking & Cybersecurity notes (English & Bangla)**  
This repository contains organized notes, cheat-sheets, and downloadable PDFs/DOCX files covering core networking, protocols, security attacks, and pentesting concepts — useful for CCNA, CEH, and general study.

---

## Overview
This repo gathers clear, structured notes on networking and cybersecurity topics. It includes both English and Bangla material, topic lists, and ready-to-download study files (PDF/DOCX). Ideal for students, sysadmins, and self-learners.

---

## Contents (high level)
- Internet fundamentals & hierarchy  
- Addressing: MAC, IPv4, IPv6, CIDR, subnetting, supernetting  
- Protocols: ARP, ICMP, IGMP, DNS, DHCP, QUIC, TCP/UDP, HTTP, TLS, VPNs  
- Network devices: hub, switch, router, AP, modem, gateway, bridge, repeater  
- Wireless: WEP/WPA/WPA2/WPA3, PSK vs Enterprise, common WiFi attacks  
- Security & attacks: ARP spoofing, DNS/IP spoofing, MAC flooding, DHCP starvation, SYN flood, MITM, sniffing, replay, session hijack, SSL stripping, routing attacks  
- Tools & techniques: netstat, traceroute, port scanning, pivoting, tunneling, reverse/bind shells  
- Downloadable study files: polished PDFs and DOCX (English + Bangla)
